# AI Abstraction Planning (Issue #80)

This folder contains the research and implementation planning artifacts for migrating AI chat calls in `AIHelper` to a provider-based abstraction.

## Contents

- `research-findings.md` – research notes comparing current Agent Framework usage with a Copilot SDK-based approach.
- `execution-plan.md` – detailed, phased implementation plan with acceptance criteria and rollback strategy.
- `rubber-duck-review.md` – independent critique of the plan and risk adjustments before implementation.

## Scope of this issue

Per issue #80, this work is planning-only. It does **not** implement code changes yet. The implementation should begin only after the spike and acceptance criteria in these docs are approved.
